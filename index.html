양봉이 스튜디오 개인정보처리방침

최종 갱신: 2026년 8월 20일

양봉이 스튜디오는 운영자 개인이 자신의 채널(양봉이랑 음봉이 — YouTube, Instagram, TikTok)에 자체 제작 영상을 업로드하기 위해 사용하는 개인용 데스크톱 도구입니다. 일반 대중에게 배포되지 않으며, 사용자는 운영자 본인 1명입니다. 타인의 계정에 접근하거나 타인을 대신하여 게시하지 않습니다.

수집·이용하는 정보

  • YouTube — YouTube Data API를 통해 운영자 본인 계정의 동영상 업로드 권한(youtube.upload 범위) 및 채널 성과 조회 권한(yt-analytics.readonly 범위)만 사용합니다.
  • Instagram — Instagram API with Instagram Login을 통해 운영자 본인 계정의 프로필 기본 정보(instagram_business_basic) 및 콘텐츠 게시 권한(instagram_business_content_publish)만 사용합니다.
  • TikTok — TikTok Content Posting API를 통해 운영자 본인 계정의 기본 프로필 정보(user.info.basic) 및 동영상 게시 권한(video.publish)만 사용합니다.
  • 타인의 개인정보를 수집·저장·공유하지 않습니다. 시청자·팔로워의 개인정보에는 접근하지 않습니다.
  • OAuth 인증 토큰은 운영자의 로컬 컴퓨터에만 저장되며 외부로 전송되지 않습니다.
  • 광고·분석·추적 도구를 사용하지 않으며, 어떤 데이터도 제3자에게 판매·제공하지 않습니다.
  • 업로드하는 영상은 전부 운영자가 자체 제작한 것이며, 타인의 콘텐츠를 재업로드하지 않습니다.

Google API 서비스 관련 고지

본 도구의 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

Meta 플랫폼 관련 고지

본 도구의 Instagram 연동은 Meta 플랫폼 약관 및 개발자 정책을 준수합니다. Instagram API로부터 받은 정보는 운영자 본인 계정에 콘텐츠를 게시하는 목적 외에는 사용하지 않으며, 제3자에게 전송하지 않습니다.

TikTok 관련 고지

본 도구의 TikTok 연동은 TikTok for Developers 서비스 약관을 준수합니다. TikTok API로부터 받은 정보는 운영자 본인 계정에 동영상을 게시하는 목적 외에는 사용하지 않으며, 제3자에게 전송하거나 다른 데이터와 결합하지 않습니다. 게시되는 동영상은 전부 운영자가 자체 제작한 원본입니다.

데이터 보관 및 삭제

본 도구는 서버를 운영하지 않으며, OAuth 인증 토큰만 운영자의 로컬 컴퓨터에 저장됩니다. 토큰은 언제든지 로컬에서 삭제할 수 있고, 각 플랫폼에서 즉시 접근 권한을 철회할 수 있습니다 — Google 계정 보안 설정, Instagram 앱 및 웹사이트 설정, TikTok 앱의 설정 > 보안 및 로그인 > 앱 관리. 철회 시 저장된 토큰은 효력을 잃습니다. 그 외에 보관되는 사용자 데이터는 없습니다.

관련 정책

본 도구는 YouTube API 서비스, Instagram API, TikTok API를 사용합니다. 사용자는 YouTube 서비스 약관, Instagram 이용 약관, TikTok 서비스 약관의 적용을 받습니다. 각 사업자의 개인정보 처리에 대해서는 Google 개인정보처리방침, Instagram 개인정보처리방침, TikTok 개인정보처리방침을 참고하세요.

Privacy Policy (English)

Last updated: August 20, 2026

Yangbong Studio is a personal desktop tool used solely by its operator to upload self-produced videos to the operator's own channels (Yangbong & Eumbong — YouTube, Instagram, TikTok). It is not distributed to the public; the only user is the operator. It never accesses another person's account or posts on anyone else's behalf.

Data We Access

  • YouTube — the YouTube Data API with the youtube.upload scope to upload videos to the operator's own account, and yt-analytics.readonly to read that channel's own performance.
  • Instagram — the Instagram API with Instagram Login, using instagram_business_basic and instagram_business_content_publish, to publish to the operator's own account only.
