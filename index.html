양봉이 스튜디오 개인정보처리방침

최종 갱신: 2026년 8월 14일

양봉이 스튜디오는 운영자 개인이 자신의 YouTube 채널(양봉이랑 음봉이)에 자체 제작 영상을 업로드하기 위해 사용하는 개인용 데스크톱 도구입니다. 일반 대중에게 배포되지 않으며, 사용자는 운영자 본인 1명입니다.

수집·이용하는 정보

  • 본 도구는 YouTube Data API를 통해 운영자 본인 계정의 동영상 업로드 권한(youtube.upload 범위)만 사용합니다.
  • 타인의 개인정보를 수집·저장·공유하지 않습니다.
  • OAuth 인증 토큰은 운영자의 로컬 컴퓨터에만 저장되며 외부로 전송되지 않습니다.
  • 광고·분석·추적 도구를 사용하지 않으며, 어떤 데이터도 제3자에게 판매·제공하지 않습니다.

Google API 서비스 관련 고지

본 도구의 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.
